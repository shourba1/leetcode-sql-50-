# Documentation conventions

This is a personal learning repository.

- Use MySQL syntax consistently unless otherwise noted.
- Name solution files `<leetcode-id>-<kebab-case-title>.sql`.
- Put each file in its corresponding study-plan topic folder.
- Keep the original problem URL and describe the approach in your own words.
- Do not mark a solution accepted until it has been tested on LeetCode.
- Update the README progress and solved-problems table when publishing.
- Prefer clear, readable SQL over clever one-liners.
- Don't copy LeetCode problem statements or other people's solution explanations.
